01 / THE APPROACH

Simulation meets
real interaction.

ROSWORLD combines simulated embodiment with a real virtual-machine interface. Models act from a given viewpoint, controlling a robotic arm or dexterous hand instead of directly issuing computer commands.

01 →

Observe

The model receives the given view of the Isaac Sim environment, including the monitor.

02 →

Act

A robotic arm or dexterous hand physically operates the simulated keyboard and mouse.

03 →

Execute

Triggered keyboard and mouse signals are sent to the virtual machine running OSWorld tasks.

04 ↩

See the result

The live VM display is rendered onto the simulated monitor, closing the perception–action loop.

DISPLAY FEEDBACK → NEXT OBSERVATION ↩

Consistent benchmark protocols

Comparative evaluations will use fixed protocols, including fixed robotic arm, dexterous hand, and humanoid robot models. Results will be presented with their corresponding evaluation setup.

Diverse assets for open research

The planned open-source repository will include diverse assets so researchers can evaluate their models across different embodiments.

02 / THE LIVING BENCHMARK

Built to evolve
with the models.

This is a long-term project. As model capabilities develop, we will introduce new tasks and keep the leaderboard updated. Results from the initial evaluation are expected before October 20, 2026.
